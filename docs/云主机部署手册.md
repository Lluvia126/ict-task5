# 云主机部署手册（方案 C：学生云主机 24/7，不用自己的电脑）

目标：把「后端 API + Neo4j + 公网入口」搬到一台便宜的学生云主机上，**彻底摆脱"自己电脑不能关机"的问题**。
前端仍然放 Cloudflare Pages（免费、云端，不需要任何机器在线）。

```
评委浏览器 ──> https://api.你的域名  ──Cloudflare 隧道──> 云主机(127.0.0.1:8000) ──> Neo4j(本机 7687)
                            ▲
               前端 Pages(Cloudflare 云端) 调用它
```

---

## 0. 买什么机器（成本 ≈ 10 元/月）

| 项目 | 建议 | 说明 |
|---|---|---|
| 厂商 | 腾讯云 / 阿里云「学生机」 | 腾讯云校园计划、阿里云飞天加速计划，2 核 2G ≈ 9.9~10 元/月 |
| 配置 | 2 核 2G / 40G 盘 起 | 够跑 FastAPI + Neo4j（Neo4j 需限制堆内存，见下） |
| 系统 | Ubuntu 22.04 / 24.04 64 位 | 22.04 自带 Python 3.10，24.04 自带 3.12，都能跑 |
| 地域 | 任意（建议就近，如广州/上海） | **不需要备案**：我们对外走 Cloudflare 隧道，不直接用 80/443 暴露域名 |
| 时长 | 买 1~2 个月 | 评审结束即可退订 |

> 备案说明：国内服务器若要用"域名 + 80/443 直接访问"，必须先 ICP 备案（7~20 天，来不及）。
> 本方案用 **Cloudflare 隧道**（服务器主动出站连接），域名解析在 Cloudflare 侧，
> 因此**完全不需要备案**，也**不需要在安全组开放任何 Web 端口**。

## 1. 安全组 / 防火墙：只开 SSH

在云控制台的安全组里**只放行 22（SSH）**。不要放 8000 / 8001 / 7474 / 7687。
隧道是出站连接，不需要入站端口 —— 这比现在的校园网方式更安全。

## 3. 装 Neo4j（二选一）

### 方式 A：apt 安装（推荐，不依赖 Docker Hub）
```bash
curl -fsSL https://debian.neo4j.com/neotechnology.gpg.key | sudo gpg --dearmor -o /usr/share/keyrings/neo4j.gpg
echo "deb [signed-by=/usr/share/keyrings/neo4j.gpg] https://debian.neo4j.com stable latest" | sudo tee /etc/apt/sources.list.d/neo4j.list
sudo apt update && sudo apt -y install neo4j
sudo neo4j-admin dbms set-initial-password '你的强密码'
sudo systemctl enable --now neo4j
sudo systemctl status neo4j --no-pager
```
2G 内存的机器请限制堆，编辑 `/etc/neo4j/neo4j.conf`：
```ini
server.memory.heap.initial_size=256m
server.memory.heap.max_size=512m
server.memory.pagecache.size=256m
```
改完 `sudo systemctl restart neo4j`。

### 方式 B：Docker（需要配镜像加速器，见第 9 节）
```bash
docker run -d --name neo4j --restart unless-stopped \
  -e NEO4J_AUTH=neo4j/你的强密码 \
  -e NEO4J_server_memory_heap_max__size=512m \
  -p 127.0.0.1:7687:7687 -p 127.0.0.1:7474:7474 \
  -v neo4j-data:/data neo4j:5-community
```
注意 `-p 127.0.0.1:...`（只绑本机），不要写成 `-p 7687:7687`（那会暴露到公网）。

## 4. 部署后端

```bash
sudo mkdir -p /opt/ict-task5 && sudo chown $USER /opt/ict-task5
cd /opt/ict-task5

# 把源码包（dist\ict-task5-backend-<日期>.zip）传上来：本机执行
#   scp dist\ict-task5-backend-20261016.zip ubuntu@<云主机IP>:/opt/ict-task5/
unzip ict-task5-backend-*.zip

python3 -m venv .venv
.venv/bin/pip install -U pip
.venv/bin/pip install -r requirements.txt

cp .env.example .env && nano .env      # 按下表填写
```

`.env`（云主机版）：

```ini
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=<第 3 步设的强密码>

# AI 抽取服务：同机部署（推荐）用 http://127.0.0.1:8001；留在前端那台就填它的局域网 IP
AI_SERVICE_URL=http://127.0.0.1:8001
QWEN_API_KEY=<前端同学提供>
QWEN_MODEL=qwen-vl-max

ADMIN_TOKEN=<python3 -c "import secrets;print(secrets.token_urlsafe(24))">
PUBLIC_MODE=1
ALLOW_ANON_UPLOAD=1
ALLOW_ANON_EXTRACT=1
QUOTA_UPLOAD_PER_IP_DAY=10
QUOTA_EXTRACT_PER_IP_DAY=20
QUOTA_EXTRACT_GLOBAL_PER_DAY=300
MAX_UPLOAD_MB=100
ALLOWED_ORIGINS=https://<前端 Pages 域名>
GRAPH_SYNC_MODE=auto
```

手工验证（先前台跑一遍）：
```bash
.venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8000
# 另开一个 SSH 窗口
curl -s localhost:8000/api/health
```

## 5. 做成 systemd 服务（开机自启，不用管）

`/etc/systemd/system/ict-task5.service`：
```ini
[Unit]
Description=ICT Task5 backend (FastAPI)
After=network-online.target neo4j.service
Wants=network-online.target

[Service]
User=ubuntu
WorkingDirectory=/opt/ict-task5
ExecStart=/opt/ict-task5/.venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8000
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now ict-task5
systemctl status ict-task5 --no-pager
```
### AI 抽取服务（同机部署，必须）

`/etc/systemd/system/ict-task5-ai.service`：
```ini
[Unit]
Description=ICT Task5 AI extraction (Qwen)
After=network-online.target
Wants=network-online.target

[Service]
User=ubuntu
WorkingDirectory=/opt/ict-task5
EnvironmentFile=/opt/ict-task5/.env
ExecStart=/opt/ict-task5/.venv/bin/python -m uvicorn ai_extraction1.api:app --host 127.0.0.1 --port 8001
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now ict-task5-ai
curl -s localhost:8001/health
# 期望：{"status":"ok","qwen_api_key_configured":true,...}
```
> 若 `qwen_api_key_configured` 为 false：`.env` 里的 `QWEN_API_KEY` 没填或没生效，
> 填好后 `sudo systemctl restart ict-task5-ai`。
>
> 页面调用的是 `ai_extraction1.api:app`（前端同学给的完整版，支持 qwen/lora 两条路径），
> 两者共用同一份 `.env`。

## 6. 公网入口：Cloudflare 隧道（免备案、免开放端口）

1. Cloudflare 后台 → **Zero Trust → Networks → Tunnels → Create a tunnel → Cloudflared** → 起名 `caizhi` → 复制 **token**。
2. 在隧道里加 **Public Hostname**：`api.你的域名` → Service 选 `HTTP` → URL 填 `127.0.0.1:8000`。
3. 云主机上装并常驻：
```bash
curl -L -o cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
sudo install -m 755 cloudflared /usr/local/bin/cloudflared && rm cloudflared

sudo cloudflared service install <粘贴token>
sudo systemctl enable --now cloudflared
systemctl status cloudflared --no-pager
```
> 这条路径连 `config.yml` 都不用写（配置在 Cloudflare 后台），比 Windows 服务那套更省事。
> 如果云主机访问 GitHub 慢，用 `docker compose` 里的 cloudflared 服务（见第 9 节）。

4. 验证：手机 4G 打开 `https://api.你的域名/docs`。

## 9. 想要 Docker 版？（可选）

本仓库已带 `Dockerfile` + `docker-compose.yml`（neo4j + backend + cloudflared + 可选 ai）。

```bash
# 国内环境必须先配镜像加速器，否则拉 python:3.12-slim 会超时（我实测确认）
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json >/dev/null <<'EOF'
{
  "registry-mirrors": ["https://docker.m.daocloud.io", "https://docker.1ms.run", "https://docker.xuanyuan.me"]
}
EOF
sudo systemctl restart docker

cd /opt/ict-task5
docker compose up -d                 # 含 AI 时：docker compose --profile ai up -d
docker compose logs -f backend
```
实测：`docker.m.daocloud.io` 可用（`/v2/` 返回 401 属正常存活）。

## 11. 常见坑（按踩到的概率排序）

1. **Docker Hub 拉不动** → 配镜像加速器（第 9 节），或直接走第 3 节方案 A（apt 装 Neo4j）。
2. **pip 装依赖慢** → 一定配清华源。
3. **2G 内存 Neo4j 被 OOM kill** → 限制 heap（`NEO4J_server_memory_heap_max__size=512m` 或 conf 里的 `server.memory.heap.max_size`）。
4. **安全组开了 8000/7474** → 千万别开，全部走隧道；`docker run` 也别写 `-p 7687:7687`。
5. **Python 版本过低** → 代码里用了 `list | None` 语法，需要 Python ≥ 3.10（Ubuntu 22.04 起自带）。
6. **域名没配 Public Hostname** → 隧道 `Registered` 了但访问域名 502/1033，回后台检查 Hostname 是否指向 `127.0.0.1:8000`。
7. **`.env` 里 ADMIN_TOKEN 空着** → 公网模式下破坏性接口会被彻底关掉（503），这是故意的安全兜底。
