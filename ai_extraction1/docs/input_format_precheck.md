## 2. 附件段渲染格式（训练口径 = 格式 A）

`make_messages_550.py::build_user` 源码（L74-80）：

```python
def build_user(aid, selected, html_cache):
    html = html_cache[aid]
    parts = ["===== 公告正文 =====\n" + preprocess_text(html)]
    for fn, ti, tb in selected.get(aid, []):
        parts.append(f"===== 第一层附件：{fn} =====\n===== 报价明细表：表格{ti + 1} =====\n"
                     + render_table(tb))
    return "\n\n".join(parts)
```

关键点：
- **每张入选表一个 part**；文件名 `===== 第一层附件：{fn} =====` 与表头 `===== 报价明细表：表格{ti+1} =====` 合并在同一个 part 内（中间单个 `\n`）。
- **文件名不去重**：同一附件下的多张表会重复出现文件名。
- parts 之间用 `"\n\n"` 连接；正文段固定为 `"===== 公告正文 =====\n" + preprocess_text(html)`。
- 表格行渲染用 `render_table`：`" | ".join(cells)`，`None → ""`，单元格内 `\n → 空格`。
